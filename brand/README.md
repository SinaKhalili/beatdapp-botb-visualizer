# Brand assets drop folder

Drop the BOTB branded assets here and I'll wire them into the Universe. Suggested
layout (rename/move as needed — just tell me what's what):

```
brand/
  fonts/        ← the title font file(s): .woff2 / .woff / .ttf / .otf
  background/   ← branded galaxy artboard(s): .png / .jpg (high-res is fine)
  planets/      ← isolated planet assets: one PNG per planet (transparent bg ideal)
```

Notes:
- For the **font**, a `.woff2` or `.ttf`/`.otf` is perfect. If the folder has a
  license/specimen PDF too, that's fine — I just need the actual font file.
- For **planets**, transparent-background PNGs work best (they'll be mapped onto
  the floating spheres / used as sprites).
- For the **background**, the largest artboard export you have.
